El Excel puede contener las columnas #, Código, Estudiante, Correo, P1, P2 y Exa. Los encabezados pueden estar en cualquiera de las primeras tres filas.

Se identifica al estudiante por Código y se guardan P1 (corte 1), P2 (corte 2) y Exa (corte 3). Las columnas #, Estudiante y Correo son informativas y no actualizan los datos del estudiante.

Las notas presentes reemplazan las guardadas del mismo corte. Las celdas vacías conservan las notas anteriores. Solo se aceptan estudiantes vinculados a este grupo. Si ocurre un error, se cancela toda la carga.

Notas entre 0 y 9,99, con hasta dos decimales. Se admite coma o punto decimal. Guarda los códigos como texto para conservar ceros iniciales. Cada código debe aparecer una sola vez.
